# Практика 2. Анализ социальной сети VK

Проект собирает два круга связей VK для участников группы и оценивает
центральность исходных участников по трём мерам:

- посредничество (`betweenness`);
- близость (`closeness`);
- собственный вектор (`eigenvector centrality`).

## Этапы работы

1. Сбор данных выполняется отдельным скриптом и сохраняется с checkpoint.
2. Notebook проверяет схему и полноту сохранённой выгрузки.
3. Наблюдения преобразуются в неориентированный граф без петель и дублей.
4. Центральности вычисляются только для исходных участников группы.
5. Notebook строит таблицы, графики и формирует выводы по текущим данным.

Notebook не выполняет сетевые запросы при обычном анализе. Это позволяет
повторно запускать расчёты без расходования лимита VK API.

## CPU-запуск

Из каталога `practice_2`:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab
```

Откройте `practice2.ipynb` и выполняйте ячейки последовательно.

Для автономной проверки старого сценария четырёх участников:

```bash
python vk_collect.py --self-check
```

Для сбора списка из `data/group_ids.csv`:

```bash
python collect_group.py \
  --members-csv data/group_ids.csv \
  --data-dir data/group \
  --cache-from data/collect_state.json \
  --env-file .env
```

## GPU-запуск

GPU нужен только для ускорения расчёта центральности. Сбор данных и CPU-анализ
остаются доступными без CUDA.

```bash
docker build -f Dockerfile.gpu -t practice-2-gpu .
docker run --rm --gpus all -p 8888:8888 \
  -v "$PWD":/home/jovyan/work \
  practice-2-gpu
```

Откройте URL, напечатанный Jupyter, и запустите `practice2.ipynb`.
Если cuGraph недоступен, `vk_analysis.py` автоматически использует NetworkX.

## Состояние данных

Выгрузка является наблюдаемым графом. Закрытые профили и незагруженные списки
не трактуются как отсутствие друзей. Сводка сбора хранит отдельные признаки
завершённости графа и загрузки профилей.

Файлы `.env`, checkpoint и сырые персональные выгрузки предназначены для
локального использования. Не размещайте действующие токены в публичном Git.
